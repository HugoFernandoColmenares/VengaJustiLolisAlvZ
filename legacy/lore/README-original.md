# VengaJustiLolisAlv Z - Sitio Web Promocional ✨

Este repositorio contiene el código fuente de la página web promocional para el juego **VengaJustiLolisAlv Z**, un ARPG/Novela Visual desarrollado en RPG Maker Ace.

El juego se centra en el humor, la parodia y una narrativa basada en eventos surgidos de un chat de WhatsApp, ambientado en un caótico espacio interdimensional conocido como "La Grieta". La página web sirve como un punto central para presentar la premisa, personajes y características del juego al público.

## 📜 Descripción del Juego (Resumen Rápido)

**VengaJustiLolisAlv Z** te sumerge en "La Grieta", un vertedero dimensional donde todos se convierten en 'lolis'. Sigue a Ralexa en la búsqueda de su hermana gemela, acompañada por la energética (y casi indestructible) Noira. Juntas explorarán Ciudad Nueva McOndo, interactuarán con personajes excéntricos y desentrañarán los misterios bajo la (a menudo ausente) supervisión del Big Onii-chan y la peculiar orden de las VengaJustiLolis. Espera una mezcla de acción RPG al estilo clásico (Zelda SNES/GBA) con el enfoque narrativo y los diálogos de una novela visual, ¡todo aderezado con mucho humor y parodia!

## 🚀 Características del Sitio Web

*   **Página de Aterrizaje Única:** Toda la información esencial en un solo lugar.
*   **Diseño Responsivo:** Se adapta a diferentes tamaños de pantalla (gracias a Tailwind CSS).
*   **Presentación Clara:** Secciones dedicadas para:
    *   Sinopsis del juego.
    *   Detalles del Gameplay.
    *   Introducción a los Personajes principales.
    *   Descripción de Facciones relevantes.
    *   Vistazo a las Locaciones clave.
*   **Estilo Visual Temático:** Utiliza colores y un diseño que intenta reflejar el tono humorístico y caótico del juego.
*   **Construido con:** HTML5 y Tailwind CSS (vía CDN).

## ⚙️ Cómo Ver el Sitio Localmente

Dado que es un sitio estático simple y usa Tailwind via CDN, no necesitas pasos de compilación complejos:

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
    ```
    *(Reemplaza `TU_USUARIO` y `TU_REPOSITORIO` con los tuyos)*
2.  **Navega a la carpeta del proyecto:**
    ```bash
    cd TU_REPOSITORIO
    ```
3.  **Abre el archivo `index.html`:**
    Simplemente haz doble clic en el archivo `index.html` o ábrelo directamente con tu navegador web preferido.

¡Y eso es todo! Deberías poder ver la página web localmente.
